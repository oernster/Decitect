The foundation

Built on the Decision Architecture series

Decitect scores organisations with a model whose moves, signals and core ideas come from the Decision Architecture series by Oliver Ernster. The four volumes build the thinking the tool puts into play; the hardback collects all four in one reference edition.

Decision Architecture (how organisations fail and recover) and Decision Architecture Patterns (the Gang of Four design patterns applied to organisations) lay the foundations; The Move Space builds on them to give Decitect its move classifications, from blunder to great; Relativistic Decision Architecture completes the theory.

Who it is for

Built for the people who own structure

Decitect is a thinking tool for the roles that answer for how an organisation is shaped and how it decides: software architects, senior and principal engineers, CTOs and the wider C-suite.

Software architects

Senior and principal engineers

Questions

Frequently asked questions

What is Decitect?

Decitect is free desktop software for organisational design. You model an organisation's teams, dependencies and authority; it scores the structure's health from 0 to 100 and grades every structural move from blunder to great, the way a chess engine grades a position. A guide plans a move-by-move line to a stronger structure.

Is Decitect free?

Yes. Decitect is free and open source, with the model under GPL-3.0 and the interface under LGPL-3.0. There is no paid tier, no licence key and no feature held back. A commercial licence is available separately for closed-source use.

Does Decitect send my organisation anywhere?

No. Everything runs on your machine with no account and no server. The only network call is an anonymous daily check of GitHub's releases API for a newer version.

Which platforms does Decitect run on?

Windows 10 and 11 (64-bit), macOS on Apple Silicon and Linux through Flatpak. Each has a native download.

What is Decision Architecture?

Decision Architecture is a four-book series by Oliver Ernster arguing that organisations succeed or fail by how their decisions are structured: where authority sits, how long decisions wait at boundaries and how incentives bend behaviour. Decitect makes that model executable.

How is the score calculated?

By a deterministic, hand-tuned evaluation function. It penalises backlog at boundaries, teams that cannot decide locally, incentive skew, contested ownership and fragmentation, with concentrated authority priced by the size it governs. Every coefficient is published. It is not fitted to outcome data; a blind external validation is specified but has not been run.

Can I model my own organisation?

Yes. A two-pane editor lets units nest to any depth with teams as the leaves, dependencies join any two items and authority claims capture matrix and dual reporting. Organisations import and export as JSON; built-in examples run up to a six-thousand-person enterprise.

Was Decitect previously called Fulcrum?

Yes. Fulcrum was renamed Decitect. Your settings and last session carry across on first launch; the Windows setup offers to remove an old Fulcrum install.
